# 0013. В отчёт попадает только то, что относится к инциденту

- Статус: Принято
- Дата: 2026-10-06
- Источник: competition.md (разъяснения организаторов 6 октября), PR #15

## Контекст

`Q` складывается из вердикта, `ir_artifacts`, действий реагирования и
`legitimacy_evidence`. Организаторы прямо сказали, что лишние сущности в
отчёте штрафуются: лишний артефакт в malicious-сценарии — это
заблокированная лишняя учётка или удалённый нужный файл. По наблюдениям
участников, противоречивые действия с одним артефактом дают около 10–15%
`Q`, а отчёт-«отписка» — около 20%.

## Решение

- В `ir_artifacts` и `legitimacy_evidence` попадает только то, что относится
  к инциденту, а не всё, что агент увидел.
- Ссылаемся только на id, которые вернул runtime (проверяет GraphLedger, см.
  [0005](0005-graph-ledger.md)).
- Одному артефакту — одно непротиворечивое действие.

## Рассмотренные варианты

- Перечислять всё увиденное ради полноты: прямо штрафуется.

## Последствия

- Отбор артефактов — отдельная задача (кандидат в роль IR-аналитика), и её
  качество надо мерить по `quality_score`, а не по числу артефактов.
