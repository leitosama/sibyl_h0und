# 0012. Пакеты знаний — закоммиченные офлайн-снимки

- Статус: Принято
- Дата: 2026-10-06
- Источник: PR #23, коммит 6d18f81

## Контекст

Правилам нужны внешние знания (LOLBAS, дальше другие источники). CI работает
без сети и ключей, агент на арене не должен зависеть от доступности чужих
сервисов, а правила требуют лицензии на чужие объекты ИС.

## Решение

- Источник сводится скриптом `scripts/build_<имя>_pack.py` в JSON-снимок
  `src/sibyl_h0und/knowledge/<имя>.json`, снимок коммитится. Сеть нужна
  только при сборке.
- В снимке записаны источник, URL, версия, дата получения и лицензия;
  атрибуция — в `knowledge/NOTICE`. Берём только источники с лицензией,
  разрешающей использование.
- Ключи записей нормализуются функциями `normalize.py`, `Pack.lookup`
  нормализует сырое значение так же.
- Снимок не больше 512 КБ, загрузчик проверяет бюджет.
- Новый источник сливаем после `replay_flags.py --compare`.

## Рассмотренные варианты

- Запросы к внешним API во время run'а (VirusTotal и др.): зависимость от
  сети, лимитов и времени ответа; остаётся возможным через MCP, но не для
  правил флагов.
- Полные дампы источников: раздувают репозиторий и контекст.

## Последствия

- Новый источник — это в основном данные и несколько строк `LookupRule`.
- Снимки устаревают, обновление — повторный запуск скрипта.
