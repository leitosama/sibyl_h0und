# 0010. Детерминированные совещательные флаги

- Статус: Заменено [0017](0017-knowledge-as-vocabulary.md)
- Дата: 2026-10-06
- Источник: PR #16, #17, #23 (issue #8)

## Контекст

Ошибки модели на `practice` — в основном неверный benign: она не замечает
подозрительного в том, что уже увидела. Подсказки должны быть
воспроизводимыми, проверяемыми офлайн и не стоить вызовов runtime.

## Решение

Слой флагов (`flags.py`, `rules.py`) оценивает сущности и связи, которые уже
вернул runtime:

- правила детерминированные: без модели, сети и часов. Правило даёт один и
  тот же результат для узла с теми же свойствами и тем же известным
  контекстом. Виды: `LevelRule` (шаблон с уровнем), `ScoreRule` (сумма
  порядковых оценок атрибутов с порогами; атрибут без данных не оценивается),
  `LookupRule` (запись в пакете знаний);
- правило может читать соседей узла через `NodeContext`, но только то, что
  runtime уже вернул; новых вызовов флаги не делают;
- контекст растёт по ходу задачи, поэтому оценка узла может измениться,
  когда приходят его новые свойства или связи. Когда приходит связь, её концы
  оцениваются заново. Находку модель видит один раз и снова — только если она
  изменилась;
- каждое правило называет источник (`nextron`, `lolbas`, `builtin`);
- модель видит только `medium` и `high`, одну строку на узел, не больше 5
  узлов на ответ, остальное — счётчиком `omitted`. В трейсе есть все находки;
- флаги совещательные: вердикт выносит модель.

Изменение правил и новый источник сливаем только после
`scripts/replay_flags.py --compare` против `main`.

## Рассмотренные варианты

- Отдавать оценку подозрительности модели-исполнителю: дороже по времени,
  невоспроизводимо и не проигрывается офлайн.
- Флаги как вето на вердикт: на маленькой выборке `practice` слишком велик
  риск сломать верные ответы.

## Последствия

- Вклад каждого источника виден в проигрывании отдельно.
- Проигрывание судит только узлы, которые открыл записанный агент, в его
  порядке, и не говорит, что модель сделала бы с флагом. Оценка узла зависит
  от того, что агент успел открыть до неё.
- Лимит в 5 флагов означает, что громкие признаки конкурируют с тихими;
  порядок — по уровню.
